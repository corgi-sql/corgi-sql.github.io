There are a few noticeable differences between CORGI and previous txt2sql benchmarks: 1. x% of the questions are recommendation or prediction based natural language queries. These queries are "soft evaluated" with human input. 2. CORGIv1.0 has business domain databases and queries, designed to test domain-specific lingo. 3. There are many more tables and relations per database in CORGI than previous benchmarks. 4. There is no test split.
